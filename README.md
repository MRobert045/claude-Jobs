# Rootstock Farm & Build — sample website

A one-page business + personal portfolio site covering three areas:

- **Farm** — chickens, eggs, pigs, tomatoes, beans and other produce, with a weekly availability table
- **Interiors & construction** — cupboard, kitchen, wardrobe and finishing installation
- **Real estate** — buy, renovate and rent (coming soon)

Plus an About section, a filterable project portfolio, and a contact form.

## View it
Open `index.html` in any browser. No build step.

## Customize
Search `index.html` for `[Your Name]`, `[Your town / region]`, `hello@example.com` and the phone number, and replace the emoji placeholders with real photos.
